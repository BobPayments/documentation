## Comece com uma chave de teste

No [Dashboard](https://app.payments.bob.company), abra o projeto e acesse **Chaves de API**.

Crie uma chave `sk_test_`. Ela não movimenta dinheiro real.

```bash
export BOB_API_KEY=sk_test_sua_chave
```

<Warning>
  Guarde a chave somente no backend.
</Warning>

## Crie sua primeira cobrança

Esta chamada retorna o `pixCode` que você mostra ao comprador:

```bash
curl --request POST \
  --url https://api.payments.bob.company/api/v1/transactions/ \
  --header "Authorization: Bearer $BOB_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: pedido-123" \
  --data '{
    "customer": {
      "name": "João Silva",
      "document": "12345678901",
      "documentType": "CPF",
      "email": "joao@example.com",
      "address": {
        "street": "Rua das Flores",
        "streetNumber": "123",
        "neighborhood": "Centro",
        "zipCode": "01310-100",
        "city": "São Paulo",
        "state": "SP"
      }
    },
    "payment": {
      "amountCents": 10000,
      "product": "Pedido 123"
    },
    "originDomain": "loja.example.com"
  }'
```

O valor `10000` representa R$ 100,00.

## Confirme pelo webhook

Cadastre uma URL HTTPS no Dashboard. Quando o pagamento for confirmado, seu backend recebe:

```json
{
  "event": "transaction.paid",
  "data": {
    "transactionId": "clx1abc123",
    "externalId": "pedido-123",
    "amountCents": 10000
  }
}
```

Valide a assinatura e libere o pedido uma única vez.
