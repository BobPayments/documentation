Você precisa implementar três ações:

1. Criar uma transação no seu backend.
2. Apresentar o `pixCode` ao comprador.
3. Confirmar o pagamento pelo webhook `transaction.paid`.

<Card title="Faça o primeiro teste" icon="bolt" href="/pages/quickstart" horizontal>
  Crie e confirme uma cobrança no sandbox usando a API REST.
</Card>

## O fluxo completo

<Steps>
  <Step title="Obtenha uma chave de teste">
    Crie uma chave `sk_test_` no Dashboard. Use a chave somente no backend.
  </Step>
  <Step title="Crie a transação">
    Envie o valor, a descrição e os dados do comprador para `POST /api/v1/transactions/`.
  </Step>
  <Step title="Apresente o PIX">
    Use o `pixCode` da resposta para mostrar o código copia-e-cola ou gerar um QR Code.
  </Step>
  <Step title="Confirme o pagamento">
    Receba `transaction.paid` em um endpoint HTTPS. Valide a assinatura antes de liberar o pedido.
  </Step>
  <Step title="Troque para produção">
    Depois de validar o fluxo no sandbox, substitua `sk_test_` por `sk_live_`.
  </Step>
</Steps>

## Chame a API pelo backend

Use qualquer cliente HTTP para chamar a API REST:

```text
https://api.payments.bob.company
```

Envie a chave no header `Authorization` e consulte os campos de cada operação na [Referência da API](/pages/pix/create).

## Regras que evitam erros

- Envie valores em centavos. `10000` representa R$ 100,00.
- Nunca exponha `sk_test_` ou `sk_live_` no navegador.
- Use `Idempotency-Key` ao criar uma transação pela API REST.
- Trate `transaction.paid` como a confirmação do pagamento.
- Processe webhooks de forma idempotente, pois uma entrega pode se repetir.
