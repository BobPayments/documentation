A Bob Payments é uma plataforma de pagamentos. Você integra uma vez e usa a mesma base para criar cobranças e receber a confirmação quando o pagamento acontecer.

## <Icon icon="buildings" type="solid" /> O que é a Bob Payments?

Hoje você pode oferecer PIX e cartão de crédito. A Bob cuida do processamento e da confirmação, enquanto a sua aplicação trabalha com uma experiência consistente. Novos métodos, como cripto, serão adicionados à mesma arquitetura quando estiverem disponíveis.

Para oferecer PIX e cartão com uma única tela, crie uma sessão de checkout no seu backend:

```javascript
const response = await fetch('https://api.payments.bob.company/api/v1/checkout-sessions/', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_test_sua_chave',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    amountCents: 10000, // R$ 100,00 — sempre centavos
    items: [{ name: 'Plano Premium', quantity: 1, unitAmountCents: 10000 }],
    paymentMethods: ['pix', 'credit_card'],
    successUrl: 'https://loja.example.com/pedido/sucesso',
    webhookUrl: 'https://loja.example.com/webhooks/bob',
  }),
});

const { data } = await response.json();
console.log(data.checkoutUrl); // redirecione o comprador para esta URL
```

```json
{
  "success": true,
  "message": "Checkout session created successfully",
  "data": {
    "sessionId": "sess_...",
    "checkoutToken": "chk_...",
    "checkoutUrl": "https://checkout.payments.bob.company/...",
    "status": "PENDING"
  }
}
```

## <Icon icon="laptop" type="solid" /> Como funciona

Duas coisas que você vai notar rápido:

1. **Endpoints que falam por si** — sem abstrações desnecessárias
   ```
   POST /api/v1/transactions/        // cria transação PIX
   GET  /api/v1/transactions/{id}    // consulta status
   POST /api/v1/checkout-sessions/   // checkout hospedado
   GET  /api/v1/customers/           // lista clientes
   ```

2. **Valores sempre em centavos, resposta sempre no mesmo formato** — `10000` = R$ 100,00, em toda a API. Sucesso vem em `{ success, data }`; erro vem em [RFC 7807](/pages/errors) com código estável.
