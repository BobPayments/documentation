title: "O que é a Bob Payments?"
description: "A infraestrutura de pagamentos para o seu produto."

A Bob Payments é uma **infraestrutura de pagamentos completa**. Integre **uma vez** para criar cobranças PIX, acompanhar cada transação em tempo real e conciliar os resultados — com checkout hospedado, SDK Checkout ou API direta.

A Bob fica entre o seu produto e o ecossistema de pagamentos: você cria uma sessão, o cliente paga e um webhook confirma o resultado.

## Como funciona

Toda integração com a Bob segue o mesmo fluxo, independente da forma de integração escolhida:

1. **Crie uma sessão de pagamento** pela API ou por um SDK de servidor.
2. **O cliente paga** — no checkout hospedado, no SDK Checkout embutido no seu site ou pelo QR Code que você mesmo renderiza.
3. **Receba a confirmação por webhook** e libere o produto ou serviço.

Você acompanha tudo pelo [Dashboard](https://app.payments.bob.company) e pela API de transações.
