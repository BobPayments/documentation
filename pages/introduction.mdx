A API Bob Payments cria cobranças PIX, devolve o `pixCode` e confirma o pagamento por webhook. Use as chamadas somente no backend.

## Como a API funciona

1. Autentique com uma chave `sk_test_` ou `sk_live_`.
2. Crie a cobrança com `POST /api/v1/transactions/`.
3. Mostre o `pixCode` ao comprador.
4. Libere o pedido só depois de receber `transaction.paid`.

A URL é a mesma em sandbox e produção. O ambiente depende da chave.

```
https://api.payments.bob.company
```

## Primeira chamada

No [Dashboard](https://app.payments.bob.company), abra o projeto e crie uma chave `sk_test_`.

```bash
export BOB_API_KEY=sk_test_sua_chave

curl --request POST \
  --url https://api.payments.bob.company/api/v1/transactions/ \
  --header "Authorization: Bearer $BOB_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: pedido-123" \
  --data '{
    "customer": {
      "name": "João Silva",
      "document": "12345678901",
      "documentType": "CPF",
      "email": "joao@example.com",
      "address": {
        "street": "Rua das Flores",
        "streetNumber": "123",
        "neighborhood": "Centro",
        "zipCode": "01310-100",
        "city": "São Paulo",
        "state": "SP"
      }
    },
    "payment": {
      "amountCents": 10000,
      "product": "Pedido 123"
    },
    "originDomain": "loja.example.com"
  }'
```

O valor `10000` representa R$ 100,00. A resposta traz o `pixCode` para o comprador pagar.

<Warning>
  Guarde a chave somente no backend.
</Warning>
