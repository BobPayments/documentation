Sua integração precisa fazer três coisas:

1. Criar uma transação no backend.
2. Mostrar o `pixCode` ao comprador.
3. Confirmar o pagamento pelo webhook `transaction.paid`.

## 1. Crie uma chave

No [Dashboard](https://app.payments.bob.company), abra o projeto e acesse **Chaves de API**.

Use `sk_test_` para testar e `sk_live_` para produção. Guarde a chave somente no backend.

[Veja como usar as chaves](/pages/authentication).

## 2. Crie a cobrança

Envie a chave no header `Authorization`:

```bash
curl --request POST \
  --url https://api.payments.bob.company/api/v1/transactions/ \
  --header "Authorization: Bearer $BOB_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: pedido-123" \
  --data '{
    "customer": {
      "name": "João Silva",
      "document": "12345678901",
      "documentType": "CPF",
      "email": "joao@example.com",
      "address": {
        "street": "Rua das Flores",
        "streetNumber": "123",
        "neighborhood": "Centro",
        "zipCode": "01310-100",
        "city": "São Paulo",
        "state": "SP"
      }
    },
    "payment": {
      "amountCents": 10000,
      "product": "Pedido 123"
    },
    "originDomain": "loja.example.com"
  }'
```

Mostre o `data.pixCode` retornado pela API. O valor `10000` representa R$ 100,00.

[Veja todos os campos e respostas da criação](/pages/pix/create).

## 3. Confirme o pagamento

Libere o pedido somente depois de receber e validar o webhook `transaction.paid`.

[Configure o webhook](/pages/webhooks).
