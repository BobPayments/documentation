A Bob Payments é uma plataforma de pagamentos. Você integra uma vez para criar cobranças PIX e receber a confirmação quando o pagamento acontecer.

## <Icon icon="buildings" type="solid" /> O que é a Bob Payments?

Você cria uma transação pela API, apresenta o código PIX ao comprador e confirma o resultado por webhook.

```javascript
const response = await fetch('https://api.payments.bob.company/api/v1/transactions/', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_test_sua_chave',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    customer: {
      name: 'João Silva',
      document: '12345678901',
      documentType: 'CPF',
      email: 'joao@example.com',
      address: {
        street: 'Rua das Flores',
        streetNumber: '123',
        neighborhood: 'Centro',
        zipCode: '01310-100',
        city: 'São Paulo',
        state: 'SP',
      },
    },
    payment: {
      amountCents: 10000,
      product: 'Plano Premium',
    },
    originDomain: 'loja.example.com',
  }),
});

const { data } = await response.json();
console.log(data.pixCode);
```

## <Icon icon="laptop" type="solid" /> Como funciona

Duas coisas que você vai notar rápido:

1. **Endpoints que falam por si** — sem abstrações desnecessárias.

   ```text
   POST /api/v1/transactions/        // cria transação PIX
   GET  /api/v1/transactions/{id}    // consulta status
   GET  /api/v1/customers/           // lista clientes
   ```

2. **Valores sempre em centavos, resposta sempre no mesmo formato** — `10000` = R$ 100,00, em toda a API. Sucesso vem em `{ success, data }`; erro vem em [RFC 7807](/pages/errors) com código estável.
