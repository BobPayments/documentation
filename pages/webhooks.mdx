Use o webhook `transaction.paid` para confirmar o pagamento. Não libere o pedido apenas porque a criação da transação retornou sucesso.

## Configure

1. Crie uma rota pública HTTPS, como `POST https://api.sualoja.com/webhooks/bob`.
2. No Dashboard, abra **Webhooks** e clique em **Adicionar webhook**.
3. Informe a URL e use a versão v2.
4. Guarde o secret em `BOB_WEBHOOK_SECRET` no seu backend.

O sandbox usa o mesmo endpoint. O campo `data.isSandbox` identifica eventos de teste.

## Receba o evento

```json
{
  "event": "transaction.paid",
  "apiVersion": "v2",
  "type": "transaction",
  "data": {
    "transactionId": "clx1abc123",
    "externalId": "pedido-123",
    "amountCents": 15000,
    "paymentMethod": "pix",
    "isSandbox": true
  },
  "timestamp": "2026-08-25T14:35:00.000Z"
}
```

| Evento | O que fazer |
|---|---|
| `transaction.created` | Registre a criação da cobrança. |
| `transaction.paid` | Confirme o pedido uma única vez. |
| `transaction.expired` | Encerre a cobrança e ofereça outra. |
| `transaction.cancelled` | Encerre a cobrança. |
| `transaction.refunded` | Marque o pedido como reembolsado. |
| `transaction.failed` | Registre a falha e ofereça outra tentativa. |

## Valide a assinatura

O header `X-Webhook-Signature` tem este formato:

```text
t=<timestamp-unix>,v1=<hmac>
```

Calcule o HMAC-SHA256 de `timestamp + "." + corpo_bruto` com o secret do webhook. Compare o resultado com `v1` e aceite timestamps com no máximo cinco minutos.

```javascript
import crypto from 'node:crypto';

function verifyWebhook(rawBody, signature, secret) {
  const match = signature?.match(/^t=(\d+),v1=([0-9a-f]{64})$/);
  if (!match) return false;

  const [, timestamp, received] = match;
  const expected = crypto
    .createHmac('sha256', secret)
    .update(`${timestamp}.`)
    .update(rawBody)
    .digest('hex');

  const receivedBuffer = Buffer.from(received, 'hex');
  const expectedBuffer = Buffer.from(expected, 'hex');
  const fresh = Math.abs(Date.now() / 1000 - Number(timestamp)) <= 300;

  return fresh
    && receivedBuffer.length === expectedBuffer.length
    && crypto.timingSafeEqual(receivedBuffer, expectedBuffer);
}
```

<Warning>
  Valide o corpo bruto recebido. Não transforme o JSON antes de calcular a assinatura.
</Warning>

Depois de validar, processe o evento e responda com HTTP `2xx`. A Bob pode enviar o mesmo evento novamente. Use `data.transactionId` e `event` para evitar processamento duplicado.

Para testar, crie uma transação com `sk_test_` e use [Simular pagamento](/pages/pix/simulate-payment).
