A Bob oferece SDKs oficiais de servidor. Eles criam cobranças PIX, consultam recursos e verificam webhooks no seu backend.

<Warning>
  As chaves `sk_live_` e `sk_test_` são secretas. Use os SDKs apenas no servidor e nunca envie uma chave ao navegador.
</Warning>

## Escolha seu SDK

| SDK | Linguagem | Quando usar |
|---|---|---|
| [SDK Node.js](/pages/sdk/node) | Node.js / TypeScript | Criar cobranças, listar transações e verificar webhooks em aplicações JavaScript ou TypeScript. |
| [SDK PHP](/pages/sdk/php) | PHP | Usar os mesmos recursos em aplicações PHP. |

## Fluxo típico

```text
Seu backend ── SDK Node.js/PHP ──> API Bob
     │                                  │
     └──── confirma o pedido <── webhook assinado
```

## Não tem SDK para sua linguagem?

Todas as operações estão disponíveis na API REST. Consulte a [Referência da API](/pages/pix/create) e chame os endpoints diretamente do seu backend.
