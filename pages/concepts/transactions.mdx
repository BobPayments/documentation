Uma transação registra uma tentativa de movimentar um valor com um método de pagamento. Ela contém o valor, o método, o cliente e o estado atual.

## Pagamento e transação

Use **pagamento** para falar da experiência completa oferecida ao comprador. Use **transação** para falar do recurso retornado pela API.

Uma sessão de checkout pode conduzir o comprador por essa experiência. A transação registra o resultado do método escolhido.

## Ciclo de vida

| Estado | O que significa |
|---|---|
| `waiting_payment` | O comprador ainda precisa concluir uma ação |
| `processing` | A Bob recebeu o pagamento e aguarda confirmação |
| `paid` | O pagamento foi confirmado |
| `expired` | O prazo para pagamento terminou |
| `cancelled` | A transação foi cancelada |
| `refunded` | O valor foi devolvido |

Os estados disponíveis podem variar por método. Implemente apenas os estados publicados na referência do fluxo que você usa.

## Como acompanhar

Use a consulta de status para atualizar a interface. No backend, processe os eventos de webhook como fonte de verdade.
