Ao final deste guia, você terá uma transação com status `paid` no sandbox. O teste não movimenta dinheiro real.

## Antes de começar

Você precisa de uma chave `sk_test_`. Se ainda não tem uma, [veja como criar a chave](/pages/authentication).

Exporte a chave no terminal:

```bash
export BOB_API_KEY=sk_test_sua_chave
```

<Warning>
  Execute as chamadas no backend. Uma chave de API nunca deve chegar ao navegador.
</Warning>

## 1. Crie uma cobrança

Use `10002` para manter a cobrança pendente até você confirmar o pagamento no próximo passo.

```bash
curl --request POST \
  --url https://api.payments.bob.company/api/v1/transactions/ \
  --header "Authorization: Bearer $BOB_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: quickstart-pedido-123" \
  --data '{
    "customer": {
      "name": "João Silva",
      "document": "12345678901",
      "documentType": "CPF",
      "email": "joao@example.com",
      "address": {
        "street": "Rua das Flores",
        "streetNumber": "123",
        "neighborhood": "Centro",
        "zipCode": "01310-100",
        "city": "São Paulo",
        "state": "SP"
      }
    },
    "payment": {
      "amountCents": 10002,
      "product": "Pedido 123"
    },
    "originDomain": "loja.example.com"
  }'
```

A resposta contém os dados que sua aplicação usa:

```json
{
  "success": true,
  "data": {
    "id": "clx7a8b9c0d1e2f3g4h5",
    "externalId": "pedido_123",
    "status": "waiting_payment",
    "pixCode": "00020126580014br.gov.bcb.pix...",
    "expirationDate": "2026-08-25T18:00:00.000Z"
  }
}
```

Guarde `data.id`. Em uma integração real, apresente `data.pixCode` ao comprador.

## 2. Confirme o pagamento no sandbox

Substitua `TRANSACTION_ID` pelo `id` retornado:

```bash
curl --request POST \
  --url https://api.payments.bob.company/api/v1/sandbox/transactions/TRANSACTION_ID/pay \
  --header "Authorization: Bearer $BOB_API_KEY"
```

O sandbox muda a transação para `paid`. Se você já configurou um webhook, ele também envia `transaction.paid`.

## 3. Consulte o resultado

```bash
curl --request GET \
  --url https://api.payments.bob.company/api/v1/transactions/TRANSACTION_ID \
  --header "Authorization: Bearer $BOB_API_KEY"
```

Confirme que o campo `status` tem o valor `paid`.

<Check>
  Seu primeiro pagamento está concluído. Agora implemente a confirmação automática por webhook antes de usar produção.
</Check>
