Para aceitar cartão de crédito você **não** envia os dados do cartão para a API Bob. O número do cartão, CVV e validade são coletados e tokenizados no navegador pelo pacote de checkout da Bob (`@bobpayments/checkout-sdk`) — a sua aplicação e a API só recebem um token seguro.

<Warning>
  Nunca envie cartão bruto (PAN, CVV ou validade) para a API Bob. Use o pacote de checkout JS da Bob para tokenizar o cartão no browser. Veja o [SDK Checkout](/pages/sdk/checkout).
</Warning>

## <Icon icon="folder-tree" type="solid" /> Estrutura

Uma transação de cartão de crédito é representada pela seguinte estrutura:

```json
{
  "id": "clx7a8b9c0d1e2f3g4h5",
  "externalId": "pedido_123",
  "amountCents": 25000,
  "product": "Assinatura Pro",
  "paymentMethod": "credit_card",
  "status": "paid",
  "card": {
    "brand": "visa",
    "last4": "4242"
  },
  "customerEmail": "joao@email.com",
  "customerName": "João Silva",
  "customer": {
    "name": "João Silva",
    "email": "joao@email.com",
    "document": "12345678900"
  },
  "createdAt": "2026-02-28T09:00:00.000Z",
  "updatedAt": "2026-02-28T09:00:00.000Z"
}
```

## Atributos:

<AccordionGroup>
  <Accordion title="id:">
    ```json
    { "id": "clx7a8b9c0d1e2f3g4h5" }
    ```
    `id` : <u>string.</u><br />
    Identificador único da transação no formato CUID.
  </Accordion>

  <Accordion title="externalId:">
    ```json
    { "externalId": "pedido_123" }
    ```
    `externalId` : <u>string.</u><br />
    Identificador da transação no seu sistema. Use para cruzar dados sem armazenar o `id` interno. Deve ser único por projeto.
  </Accordion>

  <Accordion title="amountCents:">
    ```json
    { "amountCents": 25000 }
    ```
    `amountCents` : <u>integer.</u><br />
    Valor da transação em centavos. Exemplo: `25000` = R$ 250,00.
  </Accordion>

  <Accordion title="product:">
    ```json
    { "product": "Assinatura Pro" }
    ```
    `product` : <u>string.</u><br />
    Nome ou descrição do produto/serviço cobrado.
  </Accordion>

  <Accordion title="paymentMethod:">
    ```json
    { "paymentMethod": "credit_card" }
    ```
    `paymentMethod` : <u>string.</u><br />
    Método de pagamento da transação. Para cartão, o valor é `credit_card`. O cliente da transação informa apenas o método — a rota publicada decide qual gateway processa a tentativa; o `connectionId` nunca é escolhido pelo cliente.
  </Accordion>

  <Accordion title="status:">
    ```json
    { "status": "paid" }
    ```
    `status` : <u>string.</u><br />
    Status atual da transação.
    <Info>
      | Status | Descrição |
      |--------|-----------|
      | `pending` | **Transação criada, ainda sem confirmação final** |
      | `waiting_payment` | **Aguardando autenticação 3DS ou confirmação assíncrona** |
      | `paid` | **Pagamento aprovado** |
      | `failed` | **Todas as tentativas elegíveis falharam** |
      | `refunded` | **O valor foi devolvido ao cliente** |
      | `cancelled` | **A transação foi cancelada** |
    </Info>
    Não considere apenas o HTTP `201` como confirmação de pagamento — use webhook e/ou consulta de status para confirmar o desfecho financeiro.
  </Accordion>

  <Accordion title="card:">
    ```json
    {
      "card": {
        "brand": "visa",
        "last4": "4242"
      }
    }
    ```
    `card` : <u>object | null.</u><br />
    Dados de exibição do cartão, seguros para armazenar e mostrar ao comprador. `brand` é a bandeira e `last4` são os quatro últimos dígitos. **PAN, CVV e validade nunca são retornados** — o cartão é tokenizado no browser pelo pacote de checkout da Bob.
  </Accordion>

  <Accordion title="customerEmail:">
    ```json
    { "customerEmail": "joao@email.com" }
    ```
    `customerEmail` : <u>string | null.</u><br />
    E-mail do comprador. Atalho direto ao campo `customer.email`, disponível no nível raiz da transação.
  </Accordion>

  <Accordion title="customerName:">
    ```json
    { "customerName": "João Silva" }
    ```
    `customerName` : <u>string | null.</u><br />
    Nome do comprador. Atalho direto ao campo `customer.name`, disponível no nível raiz da transação.
  </Accordion>

  <Accordion title="customer:">
    ```json
    {
      "customer": {
        "name": "João Silva",
        "email": "joao@email.com",
        "document": "12345678900"
      }
    }
    ```
    `customer` : <u>object.</u><br />
    Dados do comprador vinculado à transação. Consulte a [entidade Customer](/pages/customers/reference).
  </Accordion>

  <Accordion title="createdAt:">
    ```json
    { "createdAt": "2026-02-28T09:00:00.000Z" }
    ```
    `createdAt` : <u>date-time.</u><br />
    Data e hora de criação da transação.
  </Accordion>

  <Accordion title="updatedAt:">
    ```json
    { "updatedAt": "2026-02-28T09:05:32.000Z" }
    ```
    `updatedAt` : <u>date-time.</u><br />
    Data e hora da última atualização.
  </Accordion>
</AccordionGroup>
