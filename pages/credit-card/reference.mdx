Para aceitar cartão de crédito você **não** envia os dados do cartão para a API Bob. O número, CVV e validade são coletados e tokenizados no navegador (checkout Bob ou Bob.js/Secure Fields) — a API só recebe o token `btk_...`.

<Note>
  A integração com cartão de crédito está em **beta** e depende da habilitação no projeto.
</Note>

<Warning>
  Nunca envie cartão bruto (PAN, CVV ou validade) para a API Bob. Veja o [fluxo de cartão](/pages/credit-card/overview) e o [SDK Checkout](/pages/sdk/checkout).
</Warning>

## Criação (`POST /api/v1/transactions/`)

Corpo relevante:

```json
{
  "customer": { "...": "..." },
  "payment": { "amountCents": 25000, "product": "Assinatura Pro" },
  "paymentMethod": "credit_card",
  "card": {
    "token": "btk_...",
    "installments": 3,
    "holderName": "JOAO SILVA",
    "returnUrl": "https://loja.example.com/retorno-3ds"
  },
  "originDomain": "loja.example.com"
}
```

Resposta `201` (campos de cartão):

```json
{
  "success": true,
  "data": {
    "id": "clx7a8b9c0d1e2f3g4h5",
    "externalId": "pedido_123",
    "status": "waiting_payment",
    "cardBrand": "visa",
    "cardLastFour": "4242",
    "installments": 3,
    "nextActionUrl": "https://3ds.example.com/challenge",
    "nextAction": {
      "type": "redirect",
      "url": "https://3ds.example.com/challenge"
    }
  }
}
```

| Campo | Descrição |
|---|---|
| `card.token` | Token Bob opaco `btk_...` de uso único, emitido no browser |
| `card.installments` | Parcelas 1–12 (default 1) |
| `card.returnUrl` | URL HTTPS de volta após 3DS |
| `cardBrand` / `cardLastFour` | Dados de exibição (não sensíveis) na resposta da criação |
| `nextActionUrl` / `nextAction` | Presentes quando o emissor exige 3DS — redirecione o portador |

## Leitura (`GET /api/v1/transactions/{id}`)

A leitura devolve a transação com `paymentMethod: "credit_card"` e os campos comuns (valor, status, cliente, etc.). O desfecho final chega por webhook (`transaction.paid` / `transaction.failed`).

```json
{
  "id": "clx7a8b9c0d1e2f3g4h5",
  "externalId": "pedido_123",
  "amountCents": 25000,
  "product": "Assinatura Pro",
  "paymentMethod": "credit_card",
  "status": "paid",
  "customerEmail": "joao@email.com",
  "customerName": "João Silva",
  "paidAt": "2026-02-28T09:05:00.000Z",
  "createdAt": "2026-02-28T09:00:00.000Z",
  "updatedAt": "2026-02-28T09:05:00.000Z"
}
```

## Status

| Status | Descrição |
|--------|-----------|
| `waiting_payment` | Aguardando 3DS ou confirmação assíncrona |
| `processing` | Pagamento recebido, aguardando confirmação |
| `paid` | Pagamento aprovado |
| `refunded` | Valor devolvido |
| `cancelled` / `expired` | Transação encerrada sem aprovação |

Não considere apenas o HTTP `201` como confirmação de pagamento — use webhook e/ou consulta de status.
