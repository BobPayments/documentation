Todas as chamadas usam uma chave secreta no header `Authorization`:

```http
Authorization: Bearer sk_test_sua_chave
```

## Escolha a chave pelo ambiente

| Prefixo | Ambiente | Movimenta dinheiro real? |
|---|---|---|
| `sk_test_` | Sandbox | Não |
| `sk_live_` | Produção | Sim |

A URL base é a mesma nos dois ambientes:

```text
https://api.payments.bob.company
```

## Crie uma chave

<Steps>
  <Step title="Abra o projeto">
    Acesse o [Dashboard](https://app.payments.bob.company) e selecione o projeto da integração.
  </Step>
  <Step title="Abra Chaves de API">
    No menu lateral, clique em **Chaves de API**.
  </Step>
  <Step title="Crie e copie a chave">
    Clique em **Nova chave**, escolha o ambiente e guarde o valor. A chave aparece uma única vez.
  </Step>
</Steps>

Use uma variável de ambiente no seu servidor:

```bash
BOB_API_KEY=sk_test_sua_chave
```

<Warning>
  Nunca envie a chave ao navegador, inclua-a em logs ou salve-a no repositório. Se ela vazar, revogue-a no Dashboard e gere outra.
</Warning>

## Faça uma chamada autenticada

<CodeGroup>
```bash cURL
curl https://api.payments.bob.company/api/v1/store/ \
  --header "Authorization: Bearer $BOB_API_KEY"
```

```javascript JavaScript
const response = await fetch('https://api.payments.bob.company/api/v1/store/', {
  headers: {
    Authorization: `Bearer ${process.env.BOB_API_KEY}`,
  },
});

const project = await response.json();
```

```python Python
import os
import requests

response = requests.get(
    "https://api.payments.bob.company/api/v1/store/",
    headers={"Authorization": f"Bearer {os.environ['BOB_API_KEY']}"},
)

project = response.json()
```
</CodeGroup>

## Corrija erros de autenticação

| HTTP | Causa comum | O que fazer |
|---|---|---|
| `401` | Chave ausente, inválida ou revogada | Confira o header e gere outra chave se necessário |
| `403` | A chave não pode acessar o recurso | Confira o projeto e o ambiente da chave |
